# PetClinic Overview

Spring PetClinic is a reference sample application maintained by the Spring team to demonstrate best practices for building a Spring Boot web application. It models a simple veterinary clinic, allowing staff to manage owners and their pets, record vet visits, and browse the list of veterinarians and their specialties. The application is built with Spring Boot, Spring Data JPA, and Thymeleaf, supports three databases (H2 by default, MySQL, and PostgreSQL via Spring profiles), and is packaged as a single executable JAR runnable locally at `http://localhost:8080`.
