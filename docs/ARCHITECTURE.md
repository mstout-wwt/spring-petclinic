# PetClinic Architecture

Spring PetClinic is a monolithic Spring Boot web application organized into three layers: a **Web layer** of Spring MVC `@Controller` classes (`OwnerController`, `PetController`, `VisitController`, `VetController`, `WelcomeController`, and `CrashController`) that handle HTTP requests, validate input via Bean Validation, and render responses through the Thymeleaf template engine; a **Repository / JPA layer** of Spring Data JPA interfaces (`OwnerRepository`, `PetTypeRepository`, `VetRepository`) backed by Hibernate, which controllers call directly with no intermediate service layer; and a **Database layer** that is pluggable via Spring profiles — H2 in-memory by default, with MySQL and PostgreSQL available through the `mysql` and `postgres` profiles respectively, using plain SQL schema and seed-data scripts (Hibernate DDL auto is disabled). The project requires **Java 17 or newer** to build and run, enforced by both the Maven and Gradle build descriptors.
